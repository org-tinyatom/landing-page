Questions people ask about TinyAtom

Short answers for business teams and anyone evaluating internal tools that run on their own computers.

What is TinyAtom?

TinyAtom is the operating system and AI internal tool builder for businesses. Describe a workflow, build it with your company’s AI coding agent, then install it, share it with your teammates, and keep it updated. Tools run locally and data stays on your computer.

How do I build custom internal tools?

Start with the workflow and the people who use it. TinyAtom guides the internal tools development process: plan the screens and data, build with your AI coding agent, review what the tool can access, then package and install it on your team’s computers.

Who is TinyAtom for?

Businesses of any size with a workflow a person or small team still runs by hand. TinyAtom is for operations, support, recruiting, finance, and other teams that need software built around the way their company works.

What kinds of tools do teams build with TinyAtom?

Tools built around a workflow the company already runs: a customer-onboarding tracker, a candidate comparison tool, an implementation checklist, a reconciliation app, a document reviewer, or a weekly reporting tool. Most start from the spreadsheets, documents, exports, and API data the team already passes around.

Which AI coding agent does TinyAtom use?

TinyAtom drives Claude, OpenAI Codex, Cursor, Gemini, or a local shell agent. Your team uses the assistant it already pays for and trusts. TinyAtom handles planning, review, packaging, installation, sharing, and updates around the build.

What does TinyAtom add to an AI coding agent?

AI coding agents write the tool. TinyAtom adds the operating system around that work: a guided plan, review steps, capability checks, packaging, installation, private team sharing, and a path for publishing updated versions.

Can my team install, share, and update internal tools?

Yes. Build and review the tool once, install it locally, share it through a private company list, and publish updated versions as the workflow changes.

Do I need to run a server?

No. TinyAtom tools run on the computer where they are installed. There is no application server to host, no deployment pipeline to maintain, and no hosting bill for a tool a handful of people use.

Where is my data stored?

Each tool stores its data on your computer. Before a tool can open files or use a computer feature, TinyAtom checks that the tool asked for access and that you allowed it.

Is TinyAtom free?

Yes. TinyAtom is free to use, with no subscription and no per-seat charge for your team.

Can I install tools other people built?

Yes. Browse the public marketplace for community tools, review what each tool can access, and install the ones that fit. Businesses can also keep internal tools on a private company list. We review every tool submitted to the marketplace for security problems and bugs before it is published, and we do not allow tools that promote gambling or adult content. Review is a best effort, not a guarantee, so still check what a tool can access before you install it.
